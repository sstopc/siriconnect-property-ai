# SiriConnect Property AI

## Overview

SiriConnect Property AI is an AI-powered assistant designed for individual real estate brokers and builders.

It helps brokers:

- Manage properties
- Manage customers
- Generate AI posters
- Generate AI reels
- Share listings
- Track follow-ups
- Improve sales productivity

---

## Technology Stack

- Flutter
- FastAPI
- PostgreSQL
- Docker
- Riverpod
- SQLAlchemy
